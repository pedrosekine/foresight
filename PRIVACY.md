# Privacy

foresight runs entirely inside your browser, on Outlook on the web pages, and
nowhere else.

- It collects nothing. No analytics, no telemetry, no account, no server of
  ours.
- It sends nothing. The only network request it can make is to a theme feed
  on your own machine (`http://127.0.0.1:8787`), and only if you turn that on
  in the options and grant the permission when asked.
- It stores your settings (which view to open, colours, font, and so on) in
  Chrome's extension storage, which is yours and synced by Chrome if you sync
  Chrome.
- It reads the Outlook page in order to reduce and recolour it. Nothing it
  reads leaves the page.

Your calendar data stays between you and Microsoft, exactly as it did before.

Questions: open an issue at https://github.com/pedrosekine/foresight.
